# 🌿 DIGITAL GARDEN — E-COMMERCE UI DESIGN SYSTEM

## 01 — DESIGN DIRECTION

### Design Name

**Digital Garden**

### Visual Personality

* Organic
* Premium
* Minimal
* Warm
* Modern
* Slightly playful
* Editorial
* Soft interactions
* Natural colors
* Spacious layouts

### Design Keywords

> Organic × Premium × Minimal × Playful × Modern

### Avoid

* Pure white UI
* Pure black UI
* Generic blue
* Generic purple gradients
* Excessive glassmorphism
* Excessive shadows
* Huge rounded cards everywhere
* Too many animations
* Neon colors

16px  — Medium
24px  — Large
32px  — XL
48px  — 2XL

# 05 — BORDER RADIUS

The design should not be extremely rounded.

### Small

```text
6px
```

Use for:

* Tags
* Inputs
* Small buttons

### Medium

```text
12px
```

Use for:

* Product cards
* Images
* Buttons
* Dropdowns

### Large

```text
20px
```

Use for:

* Hero cards
* Promotional sections
* Large panels

### Organic

```text
40px 12px 40px 12px
```

Use occasionally for special editorial cards.

This asymmetry creates the organic feeling.

# 27 — ANIMATION SYSTEM

The website should feel alive, but never distracting.

## Animation Principles

Use:

```text
Fast → buttons
Medium → cards
Slow → page/hero
```

---

# MICRO ANIMATION TIMINGS

### Instant

```text
150ms
```

For:

* Hover colors
* Icon colors
* Borders

### Fast

```text
250ms
```

For:

* Buttons
* Dropdowns
* Small UI

### Medium

```text
400ms
```

For:

* Cards
* Images
* Tabs

### Slow

```text
600–800ms
```

For:

* Hero
* Large sections
* Page transitions

---

# 28 — EASING

Primary easing:

```text
cubic-bezier(0.22, 1, 0.36, 1)
```

Use this for most UI motion.

For small UI:

```text
ease-out
```

Avoid bouncy animations everywhere.

```text
48–56px
```

Text contrast should remain readable.

Never communicate information only through color.

Example:

Don't use:

```text
Green = available
Red = unavailable
```

Use:

```text
Green + Available
Red + Out of stock
```

Keep shimmer opacity low.

# 50 — THE GOLDEN RULE

The UI should feel:

```text
70% calm
20% premium
10% playful
```

The colors provide personality.

The typography provides elegance.

The whitespace provides premium feeling.

The animations provide delight.

Don't try to make every component "special."

Instead:

**Make the whole system feel consistent.**

That is what will make the e-commerce application look like a real product rather than a collection of beautiful components.
